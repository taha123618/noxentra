Noxentra Documentation

Everything you need to install Noxentra, navigate the Textual TUI or classic REPL, configure opt-in AI workflows, and run headless reconnaissance pipelines.

1. Installation

Noxentra requires Python 3.10+ on Linux (Kali, Parrot, Ubuntu) or macOS.

Recommended: pipx

shell
pipx install noxentra
noxentra

From source (development)

shell
uv sync --group dev
uv run noxentra          # Launch Textual TUI
uv run noxentra --classic # Launch classic REPL
Existing binaries reused: If a tool (such as nmap, subfinder, nuclei, or trivy) is already on your PATH via apt, brew, go, or pipx, Noxentra detects and uses it without re-cloning.

2. Quick Start & Console Grammar

Launch noxentra to open the full-screen Textual TUI. Type anywhere to filter categories and tools, or press / to open the command palette. In --classic mode, three simple prefixes cover everything:

/…Run a built-in command/engage, /find, /goal

3. Interactive Commands

4. AI Workflows (/goal, /ai & /find)

  • /ai (Recommendations): Maps plain-English requests strictly onto the 64-tag taxonomy in tags.py. It can never invent non-existent tools, and falls back to keyword matching offline.
  • /goal (Step-by-Step Planner): Calls the model once to plan commands, asks for target authorization, and pauses before every step. Tool stdout is never fed back into the planner.
  • /find (Suggest-Only Discovery): Makes zero model calls. Ranks vetted catalog tools first, then active GitHub repositories, bookmarking selections into ~/.noxentra/found.yaml without install/run commands.

5. Model & API Key Setup

The AI layer is 100% opt-in. Configure an OpenAI-compatible endpoint or a local Ollama instance via /config:

~/.noxentra/.env (mode 0600)
/config ai_base_url https://api.openai.com/v1
/config ai_model gpt-4o-mini
/config test

API keys are stored exclusively in ~/.noxentra/.env with 0600 permissions — never in config.json and never printed back.

6. Headless Orchestrator & 11 Pipelines

Run engagements non-interactively from your terminal or CI/CD runner:

noxentra --list-pipelines
noxentra --engagement acme --targets example.com,10.0.0.1 --scope-out admin.example.com --pipeline full_recon
noxentra --engagement acme --targets ./terraform --pipeline iac_scan --report --format all

7. Normalized Findings & Reports

17 built-in parsers normalize output from nmap, subfinder, dnsx, tlsx, httpx, nuclei, gobuster, ffuf, feroxbuster, whatweb, gau, katana, trivy, grype, terrascan, kube-hunter, and cloudsplaining into findings.json.

shell
noxentra --engagement acme --report --format all   # report.md, report.html, report.sarif.json
noxentra --engagement acme --ai-summary            # opt-in triage of real findings
noxentra --engagement acme --ai-report             # opt-in narrative draft (report.draft.md)

8. Security & Trust Invariants

  • List-form subprocess only: Unified runner with SIGTERM → SIGKILL escalation; no shell=True and no curl | bash installers.
  • AI plan validation: /goal plans reject sudo/doas, shell -c wrappers, and shell metacharacters before operator confirmation.
  • No forced sudo: Uses standard package managers, priv_argv detection, and user-space installs (pipx, go, brew).
  • Prompt-injection isolation: Untrusted tool output passed to --ai-summary or --ai-report is wrapped in <scan_data> delimiters.
  • Authorized targets & atomic state: Scope exclusions (--scope-out) are filtered upfront and between steps, and state files write atomically.
