AI Workflows & Interactive Console

Opt-in AI planning and discovery with deterministic offline fallbacks. Nothing auto-executes, and every recommendation resolves to vetted tools.

/goal — Step-by-step objective planner

Calls the configured model once to draft a concrete plan, asks for target authorization, and pauses before every command.

  • Workspace saved under ~/.noxentra/goals/ with plan.json and run.log
  • Every step runs list-form (shell=False)
  • Degrades to tool recommendations if no model is configured
noxentra > /goal audit terraform and kubernetes manifests Scope confirmation required for: ./infra [1] terrascan scan -i terraform -d ./infra [2] trivy fs --quiet ./infra Run step 1? [y] run · [e] edit · [s] skip · [q] abort

@tool

Jump straight to any tool card with fuzzy fallback (e.g. @nuclei, @terrascan).

@tag:<name>

Filter the catalog across 64 canonical taxonomy tags (e.g. @tag:cloud, @tag:tunneling).

/run <cmd> &

Launch long-running scans in detached tmux windows and inspect with /panes and /attach.

/engage

Create engagements, inspect X/Y ready pipeline preflight, and stream output live.

/report

Browse normalized findings by severity, kind, or tool and export MD, HTML, or SARIF.

/skill

Read the operator playbook and grounding charter governing all AI modules.
